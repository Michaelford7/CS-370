# CS-370  Pirate Intelligent Agent

**What code were you given, and what code did you create yourself?**

For this project, I was given starter code that included the maze, neural network, and experience replay. I completed the training code so the pirate could learn how to find the treasure. I also tried changing the epsilon decay rate to see if giving the pirate more time to explore would help. It was interesting seeing how one small change could make a difference in the training results.

**What do computer scientists do and why does it matter?**

Before starting my degree, I mostly thought of computer scientists as people who write programs. Now I know there is a lot more to it. They figure out how to solve problems using technology, whether that means creating something new or improving something that already exists. Their work can simplify software for an everyday non-technical user.

**How do I approach a problem as a computer scientist?**

One thing I've learned is that just because code runs doesn't mean everything is working the way it should. I experienced that with the pirate project when the agent wasn't learning as quickly as I expected. Instead of assuming something was wrong with the entire program, I had to look at the results and figure out what I could change. I think critical thinking and willingness to try different approaches and learn from mistakes is a big part of solving problems.

**What are my ethical responsibilities to the end user and the organization?**

The biggest responsibilities are making sure the technology I work on doesn't create problems for the people using it. Since I work in the financial industry, protecting personal information is something I'm already familiar with. I would want to make sure a system is secure, tested properly, and doesn't make unfair decisions based on bad information. Even if something works the way it was programmed, that doesn't always mean it's the right thing to use without considering how it affects people.
